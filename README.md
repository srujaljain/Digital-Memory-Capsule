# Digital Memory Capsule

A futuristic aesthetic web application where users can store memories, photos, and videos to unlock in the future.

# Features
- Authentication
- Future unlock dates
- Countdown timer
- File uploads
- Public/private capsules
- Envelope animations
- Confetti effects
- Dreamy aesthetic UI

# Tech Stack
Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express.js

Database:
- MySQL
